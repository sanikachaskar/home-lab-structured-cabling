# Cable Termination

## Objective

Understand Ethernet conductor order and practice cable termination using compatible tools and materials.

## Materials

* Suitable Ethernet cable
* Compatible RJ45 plugs or Cat6 keystone jacks
* Crimping tool for the selected plug, or punch-down tool for the selected jack
* Cable stripper
* RJ45 cable tester

## Procedure

1. Identify the cable category and conductor type.
2. Select either T568A or T568B.
3. Prepare the cable according to the connector manufacturer's instructions.
4. Arrange the conductors in the selected pin order.
5. Terminate both ends using compatible components.
6. Inspect the termination for loose conductors, exposed copper, and jacket placement.
7. Test the cable using an appropriate wire-map tester.
8. Record the result and photograph the completed termination.

## Acceptance Criteria

* The tester reports the expected pin mapping.
* There are no detected opens, shorts, or miswires.
* The termination is mechanically secure.
* The cable is labelled and its test result is recorded.
