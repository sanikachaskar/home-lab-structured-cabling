# Home Lab – Structured Cabling Project

## Overview

This project demonstrates the fundamentals of structured cabling and basic network infrastructure through a small home networking lab. It focuses on physical connectivity, Ethernet cable management, network device connections, IP configuration, connectivity testing, and troubleshooting.

## Objectives

* Understand Ethernet cabling and structured cabling fundamentals.
* Learn T568A and T568B wiring standards.
* Connect network devices using a Gigabit Ethernet switch.
* Practice cable identification, labelling, and organization.
* Verify cable continuity and network connectivity.
* Troubleshoot common physical and network-layer issues.
* Maintain technical documentation and test records.

## Hardware and Tools

* Existing home router
* Five-port Gigabit Ethernet switch
* Cat6 Ethernet patch cables
* Laptop or desktop with Ethernet connectivity
* RJ45 LAN cable tester
* RJ45 crimping tool
* Compatible RJ45 connectors
* Cable stripper
* Cat6 bulk cable for termination practice
* Cat6 keystone jacks
* Punch-down tool
* Small patch panel or mounting box
* Cable labels and reusable Velcro ties

Optional tools and components are used only if available.

## Implementation

1. Plan the network topology.
2. Inspect the equipment and Ethernet cables.
3. Connect the router, switch, and end devices.
4. Label and organize cables.
5. Practice cable termination using compatible components.
6. Verify cable wiring using a cable tester.
7. Check IP configuration and Ethernet link status.
8. Perform ping and connectivity tests.
9. Record failures, troubleshooting steps, and actual results.

## Testing

The project includes:

* Physical cable inspection
* Cable continuity and wire-map testing
* Ethernet link-status verification
* IP configuration checks
* Default gateway connectivity
* Local network ping testing
* DNS resolution testing
* Internet connectivity testing, when available
* Fault diagnosis and retesting

## Skills Demonstrated

* Ethernet cabling fundamentals
* Basic LAN infrastructure
* Network device connectivity
* Cable management and port labelling
* IP addressing and troubleshooting
* Technical documentation
* Systematic fault isolation
